Critical Vulnerabilities Addressed: PHP2Shell

Disclosed on October 21, 2026, PHP2Shell consists of two high-severity flaws in the core PHP interpreter affecting millions of production servers worldwide:

CVE-2026-109619 (UAF RCE)

A critical Use-After-Free (UAF) condition in PHP's built-in session.upload_progress handler. When multipart form uploads abort, cleanup routines access dangling global memory, leading to Remote Code Execution (RCE).

CVE-2026-109618 (Heap Corruption)

An uninitialized request data cleanup error triggered during Out-Of-Memory (OOM) longjmp() aborts, causing memory corruption in PHP core across versions < 8.2.35, < 8.3.36, < 8.4.27, and < 8.5.12.

Key Features of PHP2SHELL

  • Engineered by Nihal Sailor
    Built from the ground up prioritizing clean architecture, high operational reliability, and zero external dependency requirements for mission-critical servers.
  • 1-Click Automated Windows Security Patcher
    The flagship fix_php2shell.bat script automates detection, official SHA-256 integrity validation, extraction of patched PHP 8.3.36, directory junction linking, and directive hardening with zero administrative privileges required.
  • Smart 3-Scenario Pre-Scan Logic
    Intelligently classifies system state before touching files: reports Safe if PHP is not installed or already patched (hardens php.ini in-place with zero re-downloads), and initiates a clean upgrade only when vulnerable releases are detected.
  • Cross-Platform Python & PowerShell Auditing
    Includes php2shell_scanner.py and php2shell_scanner.ps1 for auditing local systems, scanning remote web applications via benign multipart probes, and generating structured JSON compliance reports.
  • Self-Hosted Single-File PHP Web Dashboard
    A zero-setup, self-contained single-file PHP web application (web/index.php) providing live server telemetry, SAPI inspection, remote website scanning tabs, and REST API endpoints.
