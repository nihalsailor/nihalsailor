Nihal Sailor (known professionally and online as Nihalsailor) is an Indian software developer, ethical hacker, and video game engineer.[1] He is the creator and maintainer of several multiplayer gaming systems, real-time communications platforms, and system security tools, including the combat vehicle multiplayer simulator WRX Battles Online, the privacy-focused device utility SafeGuard Lite, and the creative broadcast toolset StreamSailor Suite.[2]

Across his work, Sailor combines algorithmic engineering, network protocols, and dark nautical aesthetics under the digital moniker "Captain Nihalsailor".[3]

Career and development

Sailor's software engineering focus spans interactive 3D simulations, real-time networking, client-side encryption, and cyber security automation. His digital presence and creative brand are characterized by dark maritime and nautical fantasy motifs.

Game development and 3D graphics

In game engineering, Sailor utilizes the Unity engine, C#, and WebGL technologies:

  • WRX Battles Online: A high-tempo multiplayer vehicular combat title incorporating dynamic wheel suspension, client-side predictive netcode, weapon ballistics, and destructible vehicle components.[4]
  • Ghost Galleon 3D: A browser-based interactive 3D ocean simulator engineered in Three.js and custom GLSL shaders, demonstrating GPU Gerstner wave displacement and dynamic buoyancy physics in real time.
  • Unity Asset Store tools: Development of modular systems for independent game studios, including dark fantasy user interface kits (Stuck Cursed UI), multi-point ocean buoyancy algorithms, and runtime game memory encryption toolsets.

Cybersecurity and system software

Sailor has engineered several utilities addressing cybersecurity, local policy enforcement, and communication privacy:

  • SafeGuard Lite: A lightweight device management and content-filtering application engineered for Android and personal computers. The software utilizes local network packet filtering, application lockouts, and tamper-resistant background daemons to provide parental controls without relying on third-party cloud monitoring.[5]
  • ZAI Cyber Threat Radar: An automated reconnaissance and ethical penetration auditing pipeline built in Python and Docker to scan exposed endpoints, inspect open network ports, and correlate findings against known Common Vulnerabilities and Exposures (CVE) databases.[6]
  • ApaniBaat: A full-stack real-time communications application engineered with Node.js, React, and WebSocket protocol, providing end-to-end encrypted messaging, media distribution, and presence synchronization.[7]
  • StreamSailor Studio Suite: An open broadcast orchestration tool written in Python that interfaces with OBS Studio via WebSockets, featuring automated live stream triggers, responsive audio digital signal processing (DSP), and streaming platform telemetry.
