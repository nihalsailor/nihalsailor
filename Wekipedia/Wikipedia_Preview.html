Nihal Sailor (known professionally and online as Nihalsailor) is an Indian software developer, artificial intelligence systems engineer, ethical hacker, and game programmer.[1] He is the creator and maintainer of several open-source and proprietary software platforms spanning artificial intelligence orchestration, creator optimization tooling, real-time multiplayer gaming, distributed systems, and endpoint security. His notable projects include the Model Context Protocol bridge Flow Connect Free, the AI YouTube optimization suite ReachTube Studio, the vehicular combat title WRX Battles Online, the privacy-oriented device management tool SafeGuard Lite, and the creator broadcast deck StreamSailor Suite.[2]

Sailor's engineering work centers around real-time network protocols, interactive 3D simulations, agentic artificial intelligence bridges, creator toolsets, and cybersecurity automation. Across public repositories and technical releases, his digital identity is characterized by maritime and dark nautical motifs under the persona "Captain Nihalsailor".[3]

Career and development

Sailor began developing software focused on systems architecture, network latency optimization, and procedural 3D environments. His work combines rigorous low-level engineering with high-concept maritime aesthetics.

Artificial intelligence and creator tools

In 2026, Sailor expanded his development focus into agentic artificial intelligence workflows, model context protocol engineering, and content optimization platforms:

  • ReachTube Studio: An AI-powered YouTube channel growth and video optimization platform engineered for digital content creators.[4] Designed as an installable Progressive Web Application (PWA) incorporating Google Identity Services and YouTube OAuth APIs, the platform automates algorithm-calibrated introductory hooks, viewer retention pacing, tag cluster generation, and AI prompt composition for high-CTR thumbnails.[5]
  • Flow Connect Free: An open-source Model Context Protocol (MCP) bridge that connects AI coding agents (including Claude Code, Antigravity, Cursor, and Windsurf) directly to Google Flow.[6] Built with TypeScript, Chrome DevTools Protocol (CDP), and local WebSocket loopback communication, it facilitates automated hardware-level browser dispatch, clean CDN media URL extraction, and seamless Image-to-Image / Video generation via Veo 3.1 and Nano without commercial API fees.[7]

Game development and 3D graphics

In game engineering, Sailor utilizes the Unity engine, C#, and WebGL technologies:

  • WRX Battles Online: A high-tempo multiplayer vehicular combat title incorporating dynamic wheel suspension, client-side predictive netcode, weapon ballistics, and destructible vehicle components.[8]
  • Ghost Galleon 3D: A browser-based interactive 3D ocean simulator engineered in Three.js and custom GLSL shaders, demonstrating GPU Gerstner wave displacement and dynamic buoyancy physics in real time.[9]
  • Unity Asset Store tools: Development of modular systems for independent game studios, including dark fantasy user interface kits (Stuck Cursed UI), multi-point ocean buoyancy algorithms (Abyssal Dynamic Buoyancy), and runtime game memory encryption toolsets (Guardian Client Security).[10]

Cybersecurity and system software

Sailor has engineered several utilities addressing cybersecurity, local policy enforcement, and communication privacy:

  • SafeGuard Lite: A lightweight device management and content-filtering application engineered for Android and personal computers. The software utilizes local network packet filtering, application lockouts, and tamper-resistant background daemons to provide parental controls without relying on third-party cloud monitoring.[11]
  • ZAI Cyber Threat Radar: An automated reconnaissance and ethical penetration auditing pipeline built in Python and Docker to scan exposed endpoints, inspect open network ports, and correlate findings against known Common Vulnerabilities and Exposures (CVE) databases.[12]
  • ApaniBaat: A full-stack real-time communications application engineered with Node.js, React, and WebSocket protocol, providing end-to-end encrypted messaging, media distribution, and presence synchronization.[13]
  • StreamSailor Studio Suite: An open broadcast orchestration tool written in Python that interfaces with OBS Studio via WebSockets, featuring automated live stream triggers, responsive audio digital signal processing (DSP), and streaming platform telemetry.[14]
